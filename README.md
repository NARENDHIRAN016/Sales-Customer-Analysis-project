# Sales & Customer Analysis using Python

## Objective
To analyze retail sales and customer behavior data to uncover revenue drivers, customer value patterns, profitability risks, and growth opportunities, and to provide actionable business recommendations using Python-based analytics and visualization.

## Dataset Description
The project uses synthetic but realistic sales data, generated by `data/generate_data.py`. The dataset includes information such as `Order_ID`, `Order_Date`, `Customer_ID`, `Customer_Segment`, `Gender`, `Age`, `Region`, `Product_Category`, `Product_Name`, `Quantity`, `Unit_Price`, `Discount`, `Payment_Method`, `Sales`, and `Profit`.

## Analysis Performed
1.  **Data Cleaning & Preprocessing**: Handled duplicates, converted data types, and capped outliers in `src/data_cleaning.py`.
2.  **Exploratory Data Analysis (EDA)**: Visualized sales distribution and the relationship between discount and profit.
3.  **Sales Analysis**: Calculated key performance indicators (KPIs) like Total Revenue, Total Profit, Average Order Value, and Profit Margin. Analyzed sales performance by product category.
4.  **Customer Analysis**: Explored new vs. returning customers and performed RFM (Recency, Frequency, Monetary) analysis for customer segmentation.
5.  **Time Series Analysis**: Identified monthly sales trends and applied a simple moving average forecast.

## Key Insights
*   Sales are right-skewed, with a small number of high-value orders driving revenue.
*   Uncontrolled discounting erodes profit margins.
*   Electronics dominate revenue but have lower margins.
*   Returning customers contribute higher lifetime value; retention strategies are critical.
*   Clear seasonality is observed, presenting inventory and marketing planning opportunities.

## How to Run
1.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```
2.  **Generate raw data**:
    ```bash
    python data/generate_data.py
    ```
3.  **Clean data**:
    Run `notebooks/02_data_cleaning.ipynb` to generate `cleaned_sales_data.csv`.
4.  **Run analysis notebooks**:
    Execute notebooks `01_data_overview.ipynb`, `03_sales_analysis.ipynb`, `04_customer_analysis.ipynb`, and `05_time_series_analysis.ipynb` in sequence.
5.  **Run Streamlit dashboard**:
    ```bash
    streamlit run app.py
    ```
